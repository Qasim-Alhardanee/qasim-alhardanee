## 🏗️ What I'm Building

### [Uni.Link](https://turkiyeunilink.com) — Campus Ecosystem

A cross-platform (iOS + Android + Web) social network for verified university students only. Features:

| Area | What I Built |
|------|-------------|
| **Mobile App** | 40+ screens — React Native / Expo / TypeScript |
| **Backend** | PostgreSQL + Supabase (57 migrations, 16 edge functions) |
| **Auth** | JWT + email OTP + student document verification |
| **Realtime** | WebSocket-based messaging & notifications |
| **Marketplace** | Verified-only campus buy/sell/trade |
| **Admin Panel** | 12-panel dashboard — user/content/report/community management |
| **Website** | Landing page + legal docs + admin on Netlify |
| **AI Moderation** | Content filtering with automated flagging |

🔄 **Status:** Closed Beta — OMÜ Campus, Samsun  
📈 **Goal:** Turkey-wide → International
